Claude Gmail: privacy policy

Last updated: 21 November 2026.

Who uses this tool

Claude Gmail is a private tool with one user: its owner. It has no other users and collects no data from anyone else.

What it reads

With the owner's consent, the tool reads the owner's own Google account data: Gmail messages, labels and filters, Google Calendar events, Google Sheets and Google Tasks.

How the data is used

The data is used only to help the owner read, sort and organise their own mail, calendar and files. The tool does not send email.

Where the data is kept

The sign-in token and any data the tool reads stay on the owner's own computer. The tool has no server and no database of its own.

Sharing

The data is not sold. It is not shared with any third party, except that the owner's AI assistant processes it to carry out the owner's requests.

Google API Services User Data Policy

The tool's use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Removing access

The owner can remove the tool's access at any time in their Google Account, under Security, then third-party access.
